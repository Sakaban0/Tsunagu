# TsunaguChat

考えを整理して、AIに伝わる言葉へ。

質問に答えていくだけで、AIへの相談文や作業指示を作成できるWindowsデスクトップアプリです。作成した文章をコピーして、お好きなAIサービスに貼り付けて使います。

## 主な機能

- 選択肢と自由入力による質問形式のプロンプト作成
- 回答スタイルの調整、作成後の本文編集、コピー、ブックマーク
- 外部JSONによるテンプレートと回答スタイルの編集
- ライト／ダークテーマ、アクセントカラー、文字サイズの設定

Windows 10/11 x64向け。自己完結型のため、利用者側で.NETのインストールは不要です。アプリ自体はAIへの送信や回答の生成を行いません。

## 利用方法

セットアップ版は現在のユーザー専用にインストールします。管理者権限は不要です。
ポータブル版はZIPを展開し、書き込み可能な場所でTsunaguChat.exeを起動してください。

設定・ブックマーク・テンプレートはEXEの隣のdataフォルダーに保存されます。「ファイル → データの場所を開く」で確認できます。移動・バックアップする場合はdataも一緒に扱ってください。アンインストール後もdataは残ります。

配布セットには10種類のテンプレートが含まれます。EXEだけの場合は内蔵の8種類を初回生成します。旧版の保存データがある場合は初回にコピーし、元データを残します。

[操作説明](docs/USER-GUIDE.md) · [テンプレート作成依頼文](docs/TEMPLATE-GENERATION-PROMPT.md)

## 開発・配布物の作成

Windows、.NET 10 SDK、PowerShell 7を使用します。

~~~powershell
./scripts/build.ps1
./scripts/create-package.ps1
~~~

ビルドと自動テスト後、artifacts/packages内に配布フォルダーとZIPを生成します。セットアップの作成には別途Inno Setupが必要です。

[セットアップ作成手順](installer/README.md) · [開発への参加](CONTRIBUTING.md)

## データと制限

通信・テレメトリ・自動更新機能はありません。コピー後の文章をAIサービスへ送信するかどうかは利用者が判断してください。
ブックマークは暗号化せずローカルに保存します。複数起動時の同時編集は避けてください。配布EXEとセットアップにはコード署名を付けていません。
