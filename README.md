# TsunaguChat

考えを整理して、AIに伝わる言葉へ。

質問に答えていくだけで、AIへの相談文や作業指示を作成できるWindowsデスクトップアプリです。作成した文章をコピーして、お好きなAIサービスに貼り付けて使います。

## 主な機能

- 選択肢と自由入力による質問形式のプロンプト作成
- 回答スタイルの調整、作成後の本文編集、コピー、ブックマーク
- 外部JSONによるテンプレートと回答スタイルの編集
- ライト／ダークテーマ、アクセントカラー、文字サイズの設定

Windows 10/11 x64向け。自己完結型のため、利用者側で.NETのインストールは不要です。アプリローカル専用です。

## 利用方法

セットアップを現在のユーザー専用にインストールします。

設定・ブックマーク・テンプレートは実行用EXEの隣のdataフォルダーに保存されます。「ファイル → データの場所を開く」で確認できます。移動・バックアップする場合はdataも一緒に扱ってください。アンインストール後もdataは残ります。

配布セットには10種類のテンプレートが含まれます。
