# TsunaguChat 操作説明

## プロンプトを作る

1. ホームに並ぶカードから相談に近いものを選びます。
2. 別ウィンドウで最初に「回答スタイル」を設定します。項目名の右に現在値が表示されます。スライダーはクリック・ドラッグ・矢印キーで調整でき、次回も同じ位置を使います。
3. 質問に回答して「次へ」を押します。必須の質問は赤で表示します。わからなければ「スキップ（わからない）」を使えます。
4. 最後に必要なら補足を入力し、「プロンプトを作成」を押します。
5. プロンプトを読み、必要なら直接編集します。「回答スタイルを変更」を開くと、相談本文を維持してスタイルを変更できます。
6. 「コピー」を押し、AIの入力欄へCtrl+Vで貼り付け、内容を確認して送信します。「終了」でホームへ戻ります。

プロンプト確認画面の「戻る」で回答を保持して最後の質問へ戻れます。本文を手直ししている場合は再作成で置き換わることを確認します。質問では「前へ」「最初からやり直す」を使用できます。ブックマークから開いた確認画面の「戻る」はホームへ戻ります。

## ブックマーク

- しおり形のアイコンを押して名前を付けて保存します。保存時はモーダルで通知します。
- 塗りつぶしは保存済み、輪郭のみは未保存です。マウスを重ねると操作名が表示されます。
- 保存済みのアイコンを押すと、確認後にブックマークを解除します。
- メイン画面のブックマークタブで開く・名前変更・削除ができます。
- 保存済み文章の本文を編集した場合、終了時に変更を保存するか確認します。キャンセルすれば編集を続けられます。

## 設定

メニューバーの「設定」で別ウィンドウを開きます。

- 一般：ライト／ダーク／システム、HSVとHEXのカラーピッカー（適用時に保存）、文字サイズ（pt、標準11pt）、保存データの場所。
- 回答スタイル：answer_styles.jsonの質問名・両端ラベル・表示候補・出力文章・初期値を編集し「検証してファイルに適用」。選択位置は設定ファイルに別途保存します。
- 開発：テンプレートを作成・複製・編集・削除。質問、選択肢、条件、JSON、インポート／エクスポート、テストプレビューは従来どおり利用できます。

テーマの設定は変更時に保存します。色は「この色を適用」、文字サイズは「文字サイズを適用」で保存します。回答スタイルの色や内容の不正値、JSONのエラーはモーダルで案内し、保存前のファイルを維持します。

## AIで使う

「コピー」で作成した文章をコピーし、お使いのAIの入力欄に貼り付けて利用します。

## キーボード

| キー | 操作 |
|---|---|
| Tab / Shift+Tab | 項目を移動 |
| 矢印 / Space | 選択肢、スライダー、チェック |
| Ctrl+Enter | 回答スタイルから質問へ／次の質問／プロンプト作成 |
| Alt+Left | 前の質問／確認画面から戻る |
| Esc | モーダルを閉じる。保存済み文章の変更は確認あり |
| Ctrl+C / Ctrl+V | 選択テキストのコピー／貼り付け |
| Alt+H / Alt+B | ホーム／ブックマークタブ |
| Alt+F / Alt+S / Alt+E | ファイル／設定／ヘルプメニュー |

ショートカットはこのアプリにフォーカスがある間だけ動きます。



## テンプレート別の回答スタイル（1.4.0以降）

テンプレートJSONのトップレベルで "useAnswerStyle": false と指定すると、回答スタイル画面を省いて質問から開始します。確認画面の変更欄、生成文の【回答スタイル】と初心者向け末尾指示も省略します。最初の質問には「前へ」がなく、「最初からやり直す」も最初の質問に戻ります。省略時またはtrueは従来どおりです。

設定 → 開発の「共通の回答スタイルを使う」チェックでも変更できます。ブックマークは保存時の設定を保持し、テンプレートの編集・削除で変わりません。従来のブックマークはONとして読み込みます。

## 選択肢に当てはまらない場合（1.5.1以降）

選択式の質問では「自分で入力する」を選び、その下に回答を書いてください。必須質問でも、その回答だけで「次へ」に進めます。スキップは不要です。単一選択は他の選択肢と排他、複数選択は既存の選択肢と併用できます。自由入力を選んだまま空欄では進めません。

入力内容は補足ではなく回答として出力します。質問移動で保持し、やり直しで消去します。最大6000文字（質問で短い制限が指定されている場合はその文字数）です。保存していない回答をアプリ終了後に復元する機能はありません。
1.5.2以降は、自由入力欄を直接クリックするだけで「自分で入力する」が自動で選ばれます。Tabで移動した後に入力・貼り付けをした場合も自動選択されます。


## 1.6.0の保存先

保存先はEXEの隣のdataです。通常は %LOCALAPPDATA%\Programs\TsunaguChat\data です。旧AiPromptHelperフォルダーがあれば初回にコピーし、元はバックアップとして残します。新保存先の既存ファイルは上書きしません。単体EXEを移動する際はdataも一緒に移動してください。
