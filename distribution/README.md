# TsunaguChat

TsunaguChat.exeを起動し、使いたいテンプレートを選んで質問に答えてください。
作成した文章をコピーし、お使いのAIサービスへ貼り付けて利用します。

.NETの追加インストールは不要です。ポータブル版は書き込み可能なフォルダーに展開してください。
設定やブックマークはEXEの隣のdataフォルダーに保存します。移動時はdataも一緒に移動してください。
templatesとanswer_styles.jsonは初期配布用です。起動後の編集先は「ファイル → データの場所を開く」で開けます。

詳しい操作はdocs/USER-GUIDE.md、テンプレート作成はdocs/TEMPLATE-GENERATION-PROMPT.mdを参照してください。
